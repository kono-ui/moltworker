### ▼▼▼ ここから無料パート ▼▼▼

> このnoteを読み終わる頃には、三日坊主が「性格の欠陥」から「直せる設計ミス」に変わって、止まっていたテキストをもう一度開く手順が、手元に残っているはずです。

テキストは買いました。付箋も、蛍光ペンも。初日は2時間やって、2日目は30分、3日目は開いただけ。そして今日、机の上のテキストと目が合わないように夕飯を食べました。学生の頃からずっとこうです。ダイエットも、日記も、英語も。「継続できる人」と自分の間には、生まれつきの溝がある気がしてくる。意志が弱いんじゃなくて、人として何かが欠けてるんじゃないかって。

——これは、私が数年前に書いたメモの書き写しです。

数えたことがあります。資格2回、ダイエット5回、日記3回、英語4回、筋トレ4回、ブログ3回。私の挫折歴は、合計21回でした。21回目のあと、私は「意志を強くする方法」を探すのをやめて、別の問いを立てました。

**「21回、毎回同じ止まり方をしているなら、それは私の性格ではなく、再現性のある事故なのでは？」**

事故なら、原因分析ができます。分析してみたら、私の21回は、ほぼ同じ3つの設計ミスで起きていました。そして後から知ったのですが、この3つは習慣研究の分野で繰り返し指摘されてきた、三日坊主の定番の原因そのものでした。つまり、**あなたの挫折もほぼ確実に、この3つのどれか（または全部）で起きています。**

#### 三日坊主を起こす、3つの設計ミス

**ミス1：初日に飛ばしすぎている。**
初日の2時間は、実力ではなく「やる気」で走った距離です。やる気は再生可能エネルギーではないので、2日目には枯れます。すると2日目の30分が「昨日よりできなかった」という敗北として記録される。実際には30分も勉強したのにです。継続できる人は、初日をわざと物足りなく終えます。「もう少しやりたい」の残量を、翌日の燃料として持ち越すためです。

**ミス2：量の設定が「調子のいい日」基準になっている。**
「1日2時間」という計画は、残業がなく、体調がよく、気分が乗っている日にしか実行できません。つまりその計画は、月に数日しか来ない「最高の日」専用の設計です。継続の計画は逆で、「最悪の日にもできる量」を基準に立てます。最悪の日を通過できる設計だけが、30日を通過できます。

**ミス3：失敗の定義が厳しすぎる。**
あなたは3日目を「開いただけ」と表現しました。開いたなら、それはゼロではありません。継続できる人が特別なのは意志ではなく、帳簿のつけ方です。彼らは「開いただけの日」を続いた日としてカウントする。あなたは失敗にカウントする。**同じ行動が、記録の仕方ひとつで、継続にも挫折にもなります。**

——ここまでが、診断です。

原因が設計なら、直すのは設計図であって、あなたの人格ではありません。21回挫折した私は、人格はそのままで、設計だけを変えました。その結果だけ先に書くと、英語学習が3年続いています。劇的な話ではありません。1日の最低ノルマは、笑われるほど小さいままです。でも、3年です。21回の私からすると、別人の記録です。

この先の有料パートには、その設計図の引き方を、そのまま使える形で入れてあります。

- **設計1：量の再設計**——「最悪の日基準」で下限を決める具体的な手順と、下限・標準・上限の3段階設計テンプレート
- **設計2：初日と最初の2週間の設計**——物足りなく終える技術、行動を発動させる「時間と場所の錨」の張り方、やる気が出ない日のための if-then プラン
- **設計3：帳簿の設計**——「開いただけ」を資産に変える記録術（連続日数ではなく累計を数える理由）と、10秒で書ける記録テンプレート
- **復帰プロトコル**——それでも途切れた日のための、72時間以内の復帰手順。三日坊主対策の本体は、実はここです
- **つまずきQ&A 7問**——「アプリの連続記録が切れて萎えた」「2週間で飽きた」「そもそもこの目標でいいのか分からなくなった」など
- **再開30日プラン**——止まっているそのテキストを、どの順番で再開するかのカレンダー
- **巻末付録：机に貼る設計カード**——挫けそうな日に見る1枚

980円にしました。参考書1冊より安い金額ですが、参考書は、開かれなければ1ページも効きません。このnoteは「開き続けるほう」を担当します。あなたの本棚で眠っている教材たちを全部起こせるなら、安い投資のはずです。

最後に、購入前にひとつだけ。

このnoteは、あなたの過去の21回（あなたの数字に置き換えてください）を、一度も「甘え」と呼びません。あれは失敗の記録ではなく、21回分の事故データです。データがある人ほど、設計は速く直せます。

### ▼▼▼ ここから有料パート ▼▼▼

#### 設計1：量の再設計——「最悪の日」を基準にする

最初にやるのは、勉強時間を増やすことではなく、**下限を破壊的に小さくすること**です。

3段階で設計します。

```
【下限】最悪の日（残業・体調不良・気分最悪）でも実行できる量
　　　　例：テキストを開いて1ページ読む／単語を3個見る
【標準】ふつうの日の量
　　　　例：25分（タイマー1本分）
【上限】調子のいい日でも、ここで止める量
　　　　例：50分まで
```

ポイントは3つあります。

**下限は「笑ってしまうほど小さく」。**　1ページに違和感があるなら「開くだけ」でもいい。ばかばかしく感じるのは正常で、そのばかばかしさが保険料です。下限の役割は学習効果ではなく、「今日もやった」という事実を絶やさないこと。習慣は、量ではなく頻度でできています。

**上限を設けるのが、実は一番大事。**　調子のいい日に3時間やると、翌日の脳は「またあの重さが来る」と学習して、着手のハードルが上がります。ミス1（初日に飛ばしすぎ）は、初日だけでなく全期間で起こるんです。上限は、未来の自分への飛ばしすぎ防止装置です。

**達成判定は、下限で行う。**　1ページ読んだ日は「やった日」です。標準に届かなくても、です。ここを譲ると、ミス3（失敗の定義が厳しすぎ）が再発します。

#### 設計2：初日と最初の2週間——「もう少しやりたい」で終える

再開初日（あるいは新しい挑戦の初日）のルールは1つだけです。**標準量の半分で、強制終了する。**

まだやれる感覚が残っているうちに閉じる。この「未完了の感覚」は、心理学ではツァイガルニク効果として知られていて、中断された作業ほど頭に残り続けます。つまり、物足りなく終えた日の夜は、脳が勝手に「続きが気になる」状態を作ってくれる。翌日の着手が、軽くなります。

次に、行動の「錨」を張ります。「毎日やる」は計画ではありません。**「いつ・どこで」が決まっていない行動は、毎日、意志力で時間を確保する闘いになる**からです。既にある習慣の直後に接続してください。

```
if-then プランの型：「（既存の習慣）したら、（新しい行動）する」
例：
・朝のコーヒーを淹れたら、テキストを開く
・昼休みに席に戻ったら、単語アプリを3個だけ見る
・歯を磨いたら、机に座る（座るだけでもカウント）
```

そして、やる気が出ない日のための if-then も先に作っておきます。「疲れて何もしたくない日は、下限（開くだけ）に自動で切り替える」。**判断を当日にさせないことが、この設計の核**です。当日のあなたは、必ず今のあなたより疲れています。疲れた人に判断させず、元気な今のあなたが全部決めておく。

最初の2週間は、量を増やしたくなっても増やさないでください。2週間は「行動を錨に定着させる工事期間」で、工事中に載せる荷物は軽いほどいい。増量は3週目からです。

#### 設計3：帳簿の設計——「開いただけ」を資産に変える

記録は、次の形式で1日1行。10秒で書けます。

```
日付｜やったか（◯／下限◯／−）｜一言（任意）
7/8｜◯｜25分
7/9｜下限◯｜開いて2ページだけ
7/10｜−｜飲み会
```

ルールは3つ。

**1．「下限◯」は完全な◯としてカウントする。**　月末に数えるのは「◯＋下限◯」の合計です。この帳簿では、開いただけの日は、成功です。

**2．連続日数を数えない。累計を数える。**　「連続◯日」は強力なモチベーションですが、構造的な欠陥があります。1日の欠落で資産が全額ゼロになることです（あの学習アプリの炎が消えた朝の絶望は、これです）。累計は違います。「今月18日やった」は、1日休んでも18のまま。**減らない数字だけが、長期戦の味方になります。**

**3．「−」の日に理由を1語だけ書く。反省文は禁止。**　「飲み会」「発熱」「気力ゼロ」。これは自責の材料ではなく、あなたの阻害要因の統計です。1ヶ月分たまると「私は水曜に落ちやすい」等のパターンが見えて、設計1の下限適用日を予測できるようになります。

#### 復帰プロトコル——途切れた日のための手順（このnoteの本体）

ここまでの設計をしても、途切れる日は来ます。旅行、繁忙期、体調不良。**三日坊主の正体は、実は「3日で止まること」ではありません。「止まったあと、再開の手順がないこと」です。**止まらない人はいない。再開できる人と、できない人がいるだけです。

だから、復帰の手順を先に決めておきます。

**ルール1：72時間以内に、下限だけやる。**　空白が3日を超えると、再開のハードルは日ごとに複利で上がります（「もう1週間空いたし」「キリのいい月曜から」——この言い訳の生成が始まる前に戻る）。復帰日はフルの標準量をやってはいけません。下限だけ。「戻る」こと自体が、その日の成果です。

**ルール2：空白を埋め合わせない。**　「3日休んだから今日は3倍」は、ミス1の再発です。過去の空白は、帳簿の上ではただの「−」で、負債ではありません。累計は減っていないのだから、埋める必要のある穴は存在しない。今日の1日分だけをやります。

**ルール3：再開日を「2回目の初日」として扱う。**　設計2の初日ルール（物足りなく終える）を再適用する。再開はやり直しではなく、周回です。周回数が増えるほど、あなたの帳簿には「止まっても戻れた」という記録が増える。**自分との信頼は、無敗記録ではなく、復帰記録で作られます。**

#### つまずきQ&A

**Q1．学習アプリの連続記録が198日で切れて、アプリごと開けなくなりました。**
連続日数という指標の設計欠陥が起こした事故で、あなたの198日分の英語力は1日も消えていません。対処は2つ。アプリ内の連続記録は「参考値」に格下げし、自分の帳簿（累計制）を正とする。そして再開初日は、アプリの一番簡単なレッスンを1個だけ。カウンターの数字ではなく、「切れても戻った」という事実の方を、今後のお守りにしてください。

**Q2．2週間で飽きました。三日坊主は超えたのに、今度は倦怠期です。**
順調です。飽きは、行動が「非日常」から「日常」に変わったサインで、やる気の火が消えたのではなく、火が要らなくなった段階です。ここで刺激を求めて教材を変えると、初日リセットがかかってミス1に戻ります。対処は「変化は2割まで」。教材はそのまま、場所や時間帯だけ変える。カフェでやる、朝を夜にする。中身を守って、包装だけ変えてください。

**Q3．仕事が繁忙期に入って、標準量が2週間できていません。**
2週間「下限」が続いているなら、それは停滞ではなく、悪天候の中の航行継続です。帳簿の◯は途切れていないはずです。繁忙期は下限だけで通過する期間だと、堂々と定義してください。標準に戻すのは、繁忙期が終わってから1週間かけて段階的に。

**Q4．家族に「また始めたの？」と笑われて、心が折れそうです。**
過去の挫折を見てきた人の、悪気の薄い定型句です。反論は不要で、宣言もしない方がいい（宣言は満足感を先払いして燃料を減らします）。おすすめは「静かに帳簿だけ見せられる状態」を作ること。3ヶ月後、累計60日の記録は、どんな宣言より雄弁です。それまでは、この挑戦をあなたと帳簿だけの秘密にしておく。

**Q5．複数の習慣（勉強と筋トレと早起き）を同時に始めたいです。**
気持ちは分かりますが、錨（設計2）は一度に1本しか打てません。優先度1位だけを2週間定着させて、3週目に2本目を追加してください。同時に3本始めるのは、21回の挫折歴の再現実験になります。

**Q6．やっていて「そもそもこの資格、本当に要るのか」と思い始めました。**
2種類あります。継続がつらいことの言い訳として目標を疑い始めたのか、続けて視界が開けたことで本当に目標がずれて見えたのか。見分け方は、下限を続けたまま2週間考えること。やめてから考えると、判断が「継続のつらさ」に汚染されます。続けながら出した「やめる」は正しい戦略変更で、止まった状態で出した「やめる」は、たいてい設計ミスの症状です。

**Q7．この設計で、本当に間に合いますか。試験まで4ヶ月しかありません。**
下限1ページでは間に合わない、という不安ですね。誤解を解いておくと、下限はあくまで最悪の日の保険で、実際の月の大半は標準量（25〜50分）が回ります。累計で見てください：標準25分×月22日＋下限×月8日でも、月10時間前後。ゼロで終わった過去の4ヶ月と比べれば、答えは明らかです。間に合わせる敵は、量の少なさではなく、途中の全損（挫折）です。この設計は、全損保険です。

#### 再開30日プラン

- **1週目：**下限・標準・上限を紙に書く（設計1）。錨とif-thenを1本決める（設計2）。毎日、下限だけでいいので実行。帳簿開始
- **2週目：**標準量の日を週3日まで増やす。まだ物足りなさを残して終える。「−」の日の理由メモから、自分の阻害パターンを1つ見つける
- **3週目：**標準量を基本にする。阻害パターンの日（例：水曜）を、あらかじめ「下限適用日」として設計に組み込む
- **4週目：**わざと1日休んで、復帰プロトコルを演習する（本番の途切れが来る前に、避難訓練をしておく）。月末に累計を数えて、1ヶ月前の自分に見せたい1行を帳簿に書く

30日後のあなたは、「意志の強い人」にはなっていません。**最悪の日の通り方と、途切れた日の戻り方を知っている人**になっています。3年続く人の正体は、それだけです。

#### おわりに

21回挫折した私の帳簿には、いま「累計」の欄だけがあります。連続記録は、もう見ていません。

先月、風邪で3日空きました。昔の私なら、そこで終わっていました。「ほら、やっぱり続かない」と、21回目と同じ台詞を言って。今回の私は、4日目の夜に、テキストを開いて1ページだけ読んで、帳簿に「下限◯」と書いて寝ました。劇的なことは何も起きていません。でも、この地味な1行が、21回の私と今の私の、全部の違いです。

机の上の、目を合わせられなくなっているそのテキストへ。
明日、1ページだけ。それはもう、22回目の挑戦ではなく、1周目の続きです。
