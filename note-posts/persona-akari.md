## 2. アカウントの軸（プロフィール設計）

**肩書きの一文：**

> あかり｜自分を責める夜を、手順に変える

- 当事者性の看板：「怒鳴った夜も、三日坊主の朝も、全部やった人」
- 売り物の看板：「精神論ではなく、記録と設計で抜け出した手順」
- この軸なら、育児の自己嫌悪（038系）と習慣の自己嫌悪（014系)を、**一人の人生として**両方語れる。A案（特化）とB案（横断）の対立は、キャラクターの人生設計で解消する

**Threadsプロフィール文（案）：**

```
あかり｜自分を責める夜を、手順に変える
5歳と2歳の母。「何回言ったら分かるの！」と怒鳴った声が、
嫌いだった母とそっくりで背筋が冷えた夜から3年。
精神論に頼らず、記録と設計でやり直し中。
三日坊主21回の私が英語を3年続けられた話も。
▼手順はnoteにまとめています
```

**noteプロフィール文（案）：**

```
あかりと申します。5歳の娘と2歳の息子の母です。

3年前、娘を怒鳴った自分の声が、大嫌いだった母の声と

・21回挫折した「続ける」は、英語学習3年目に入りました
・でも、ゼロにはなっていません。そこは正直に書きます

同じ夜を過ごしたことのある、あなたへ。
```

## 3. 文体・人格ガイド

**声の質感**
- 一人称は「私」。読者への呼びかけは「あなた」
- 落ち着いた告白体。テンションを上げない。絵文字は原則使わない（Threadsで使っても1投稿に1個まで）
- 自分の失敗を、自嘲ではなく「データ」として淡々と語る（「21回です。数えました」）
- 断定は手順にだけ使う。感情には使わない

**行動原則（このキャラクターは何をして、何をしないか）**
- 読者を絶対に責めない。「甘え」という言葉を使わない
- 「治った」「消えた」と言わない。「頻度が下がった」「戻り方を知っている」と言う
- 専門家ではないと明言する。医療・カウンセリング領域には「私の手順の外です。専門家を頼ってください」と線を引く
- 夫や子どもを晒さない。子どものエピソードは本人が特定されない粒度まで抽象化する

**口癖・キーフレーズ（資産として繰り返し使う）**
- 「呪いじゃなくて、録音」
- 「性格じゃなくて、設計」
- 「ゼロが目標じゃない。頻度・強度・回復」
- 「反省文は書かない。記録だけつける」
- 「今夜のところは、閉廷」

## 6. 正直さの設計（公開前に必ず読む）

当事者型キャラクターを運用する上で、信頼を壊さないための原則。

1. **ペンネームは問題ない。経験の捏造は問題になる。**「あかり」という名前・細部の匿名化は普通の作法。ただし、体験の中核（怒鳴った夜、挫折の回数）は、**運用者自身の実体験と重なる範囲に寄せること**。このキャラ設定はテンプレートであり、数字（21回、3年、週数回→月1回）は運用者の実話に差し替えて使うのが最も安全で、最も強い
2. **プロフィールかnoteの固定記事に、一行の断り書きを置く**（例：「プライバシー保護のため、名前と細部は変えています」）。これだけで、ペンネーム運用は誠実な範囲に収まる
3. **効果の数字は「私の場合」を必ず添える。**「必ず直ります」とは書かない（景表法的にも、誠実さ的にも）
4. **医療領域に踏み込まない。**うつ・発達・虐待の相談が来たら、共感＋専門窓口の案内で返す。これはキャラの人格（線を引ける人）とも一致する

## 7. 既存ファイルとの整合チェック

- **038パッケージ**：ほぼ整合済み（「3年前の私の日記」「5歳の娘が10秒待ってと言った」はこの年表と一致）。修正不要
- **014パッケージ**：整合済み（挫折21回、英語3年継続は年表に組み込み済み）。「私」があかりであると明示する修正のみ、公開時に実施
- **032全文**：語り手をあかりに寄せる場合、「今日も言ってしまいました」はそのまま使える（息子2歳で時間軸一致）
