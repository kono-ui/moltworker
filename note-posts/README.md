# たった一人に刺さるnote 100本ノック

「私のクセ毛を分かってくれる美容師」に指名が入るように、「私の悩みを分かってくれるnote」に読者は指名で来る——その構造で創作したポスト集です。

## 設計思想

- **❶タイトル**：誰の話かがすぐわかる粒度（属性×状況×感情まで絞り込む）
- **❷ヘッダー**：読み終わった後の感情を先に約束する
- **❸冒頭200字**：たった一人の悩みを完璧に代弁し、「これは私のための文章だ」と錯覚させる

## ファイル構成

| ファイル | 内容 |

| [posts-011-020-full.md](./posts-011-020-full.md) | 011〜020の記事全文（仕事・キャリア 後半） |
| [posts-021-030-full.md](./posts-021-030-full.md) | 021〜030の記事全文（恋愛・結婚） |
