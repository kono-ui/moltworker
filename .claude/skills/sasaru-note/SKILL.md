# たった一人に刺さるnote 制作スキル

## 基本思想（すべてのモードに共通）

「技術がずば抜けた美容師」ではなく「私のクセ毛を分かってくれる美容師」に指名が入る。
文章も同じで、たった一人の悩みまで解像度を上げた記事に、読者は指名で来る。

### ❶❷❸原則

- **❶タイトル**：誰の話かがすぐわかる粒度まで絞る。「今の仕事が向いてない気がする30代前半の私へ」の粒度
  - 絞る道具：数字（年齢・回数・期間・金額）／本人の口癖・他人に言われた台詞の引用／行動の癖（ブックマークだけした、消しては入れ直す、開いては閉じる）
  - 原則「絞るほど広がる」。万人向けに書いた瞬間、誰の指名も取れない
- **❷ヘッダー**：読み終わった後の感情を先に約束する。引用ブロックで冒頭に置く
  - 解決や情報ではなく感情状態を約束する（「肩の力が抜ける」「自分を責める夜が終わる」「◯◯が△△に変わる」）
  - 読者は情報ではなく「読み終わった後の自分」を買っている
- **❸冒頭200字**：たった一人の悩みを完璧に代弁する。一人称の独白体
  - 感情の説明ではなく「行動の癖」を書く（検索履歴、既読の数を数える、テキストと目が合わないように夕飯を食べる）
  - 本人も言語化できていない「矛盾」を書く（好きなのに辞めたい、感謝しているのに恨みたい、本心なのに演技だった気がする）
  - 「なんで分かるの」と思わせたら指名成立

### 共通の文体ルール

- 正論に傷ついた人の側に立つ。世間の正論（「聞けばいいじゃん」「自己分析が足りない」「歳のせいだよ」）を先に引用し、それが効かない理由を代弁する
- 読者を一度も責めない。読者はすでに誰よりも自分を責めた後に来ている
- 精神論より「手順」「再定義」「リフレーム」。悩みに正確な名前をつけ直す（例：呪い→録音、三日坊主→設計ミス、未練→愛情の溝）
- 綺麗事の約束をしない。「ゼロになる」ではなく「頻度が下がる」と書く誠実さ
- 締めの一文は必ず❷で約束した感情に着地させる

## モードA：ポスト案の量産

依頼例：「刺さるポストを◯個考えて」

各ポストは次の4点セットで出力する：

```
### NNN｜（タイトル）
**ヘッダー（読後の感情）**：（読後の感情の約束）
**冒頭200字**：（一人称の代弁、180〜210字）
**解説**：❶❷❸をどう使ったかを2〜3文で分析
```

- ジャンルを分散させる（仕事・恋愛結婚・家族育児・お金・健康メンタル・人間関係・学び創作・暮らし人生）
- 数字は中途半端に具体的なものが実在感を生む（「198日」「フォロワー43人」「0.5秒」）
- 同じ属性でも「時期」で別の一人になる（フリーランス1年目と2年目は別の読者）

## モードB：記事の全文化

依頼例：「◯番を実際のポストの形で」「全文化して」

構成テンプレート（1本あたり1,000〜1,300字目安）：

1. `# NNN｜タイトル`
2. `> ヘッダー`（読後感情の約束。「〜はずです」「〜ています」の予告形）
3. 冒頭200字（モードAのものをそのまま使い、切れ目なく本文へ）
4. **正体の分解**：悩みに正確な名前をつけ直す。診断の掛け替え（「あなたの問題はXではなくY」）
5. **小さな一歩**：今日〜今週できる、笑ってしまうほど小さい行動。番号付きで2〜3個。実際のセリフ・テンプレートを渡す
6. **締めの一文**：❷の約束に着地。タイトルの相手に直接返す言葉で終える

## モードC：Threads→有料note 動線パッケージ

依頼例：「◯番をThreads投稿から有料noteの動線を含めて長編化して」

出力は3部構成＋設計メモ：

### ① Threads投稿セット（4本・役割分担）
- **投稿A（体験談型・起点）**：冒頭200字の内容を改行多めのThreads文体に変換。「調べて分かったんだけど」で核心の再定義を1つだけ見せ、noteへ誘導
- **投稿B（共感型）**：別角度から同じ読者の網を広げる
- **投稿C（実用型）**：ノウハウを1つだけ試食として出し切り、保存を狙う
- **投稿D（金言型）**：引用したくなる一文。ツリーにぶら下げる
- リンクはツリー末尾かプロフィールに置く（1投稿目のリンクはリーチ減衰）

### ② noteの無料パート
- ❷ヘッダー → ❸冒頭200字 → 「これは過去の私の日記」の種明かし（当事者性で信頼構築）
- 「精神論はもう足りている。足りないのは手順」の宣言
- **世界観の転換（核心の再定義）までは無料で出し切る**。出し惜しむと信頼が作れない
- 有料部分の目次を具体的に見せる＋価格の理由を本文中で説明（価格への納得を先回り）
- 「このnoteはあなたを一度も責めません」等、購入前の約束で締める

### ③ 有料パート（5,000〜8,000字目安）
- 手順を3ステップで構成。各手順に、そのまま使えるテンプレート・実際のセリフ・年齢/状況別の文例を必ず付ける
- **つまずきQ&A**（5〜7問）：実践して失敗するパターンを先回りして回答
- **30日プラン**：手順の導入順序をカレンダー化
- **巻末付録**：冷蔵庫に貼れるカード等、1画面に収まる要約物
- おわりは著者の物語の続き（変化の証拠となる具体的エピソード）で希望に着地
- 「ゼロにはならない」と正直に書き、成功の定義を頻度・強度・回復速度に置き直す

### 設計メモ
- 無料/有料ラインの位置の意図、価格設定の理由、Threads各投稿の役割をファイル末尾に記録する

## 出力・保存のルール

- 保存先はこのリポジトリの `note-posts/` ディレクトリ
- ファイル命名：量産リストは `100-personalized-posts.md`、全文化は `posts-NNN-NNN-full.md`、動線パッケージは `NNN-threads-to-paid-note.md`
- 新しいファイルを追加したら `note-posts/README.md` の目次テーブルに1行追加する
- コミットして `main` に直接プッシュする（ユーザー承認済みの運用）
- 書き終えたら文字化け・英単語の混入をチェックする：`grep -n '[a-zA-Z]{3,}' <file>` で note/SNS/LINE/PC/Photoshop 等の意図的な語以外が出ないこと、`grep -c '�' <file>` が0であること
